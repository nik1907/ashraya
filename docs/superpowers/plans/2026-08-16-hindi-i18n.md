# Hindi i18n — Volunteer Pages (Stage 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Hindi language support to all volunteer-facing pages using next-intl, with a language switcher that persists selection via cookie.

**Architecture:** next-intl (no URL-prefix routing) — locale is read from a `locale` cookie in `i18n/request.ts` and switched via a server action + `router.refresh()`. English remains the default; adding Hindi requires only a new `messages/hi.json`. Admin, embassy, and ambassador pages are untouched.

**Tech Stack:** next-intl, Next.js 16 App Router, React 19, server actions, cookies API

### Task 2: i18n infrastructure — request config, locale action, next.config

**Files:**
- Create: `i18n/request.ts`
- Create: `lib/actions/locale.ts`
- Modify: `next.config.ts`

- [ ] **Step 1: Create `i18n/request.ts`**

```ts
import { cookies } from 'next/headers'
import { getRequestConfig } from 'next-intl/server'

const SUPPORTED = ['en', 'hi'] as const
type Locale = (typeof SUPPORTED)[number]

export default getRequestConfig(async () => {
  const store = await cookies()
  const raw = store.get('locale')?.value ?? 'en'
  const locale: Locale = SUPPORTED.includes(raw as Locale) ? (raw as Locale) : 'en'
  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  }
})
```

- [ ] **Step 2: Create `lib/actions/locale.ts`**

```ts
'use server'

import { cookies } from 'next/headers'

const SUPPORTED = ['en', 'hi']

export async function setLocale(locale: string): Promise<void> {
  if (!SUPPORTED.includes(locale)) return
  const store = await cookies()
  store.set('locale', locale, { path: '/', maxAge: 60 * 60 * 24 * 365 })
}
```

### Task 4: LanguageSwitcher component

**Files:**
- Create: `components/LanguageSwitcher.tsx`

- [ ] **Step 1: Create the component**

```tsx
'use client'

import { useRouter } from 'next/navigation'
import { useTransition } from 'react'

import { setLocale } from '@/lib/actions/locale'

const LOCALES = [
  { value: 'en', short: 'EN',  label: 'English' },
  { value: 'hi', short: 'हिं', label: 'हिंदी'  },
] as const

export function LanguageSwitcher({ current }: { current: string }) {
  const router = useRouter()
  const [isPending, startTransition] = useTransition()

  function handleSwitch(locale: string) {
    if (locale === current) return
    startTransition(async () => {
      await setLocale(locale)
      router.refresh()
    })
  }

  return (
    <div className="flex gap-1" aria-label="Language">
      {LOCALES.map((l) => (
        <button
          key={l.value}
          onClick={() => handleSwitch(l.value)}
          disabled={isPending || l.value === current}
          title={l.label}
          className={`rounded border px-2 py-0.5 text-xs font-medium transition-colors ${
            l.value === current
              ? 'border-brand-saffron bg-brand-saffron/20 text-brand-saffron'
              : 'border-white/30 text-white/70 hover:border-white/60 hover:text-white'
          } disabled:opacity-50`}
        >
          {l.short}
        </button>
      ))}
    </div>
  )
}
```
