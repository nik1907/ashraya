Section 2 — What Claude Checks

Runs automatically after every volunteer submission. Takes ~3 seconds. Output is a brief structured note for the admin — not a decision.

✓ Completeness check

For this case type, are all expected fields present? Employer name for labour cases, location for missing persons, date of incident. Flags what's missing specifically.

✓ Narrative consistency

Does the narrative match the case type? A "Death" case with no mention of what happened, or a "Missing Person" case where the person apparently called yesterday — flagged as inconsistent.

✓ Document checklist

Were any attachments uploaded? For a death case, is there a medical report or police report? Flags "No documents attached — Embassy will likely request these."

✓ Red flag detection

Obvious implausibilities — future dates, contradictory details, generic filler text. Not a fraud verdict — just a note for the admin to look closer.

Sample AI pre-screening output (what admin sees)
✓ Narrative consistent with Repatriation of Mortal Remains case type.
⚠ Employer name missing — Embassy may need this for next-of-kin notification.
⚠ No documents attached — death certificate or hospital report typically required.
✓ Contact details present — reporter phone and family contact both provided.
Confidence: case appears genuine. Recommend approving with a note to volunteer to attach documents.

Note: Passport numbers and Emirates IDs are never sent to Claude — already enforced in the codebase.
